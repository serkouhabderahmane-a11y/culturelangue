Objectif du test

Ce test permet d'obtenir une première évaluation fiable de votre niveau de français.

Vos réponses nous aideront à vous orienter vers le groupe le plus adapté, afin d'optimiser votre progression.

Instructions

Répondez à chaque question en choisissant une seule réponse.

Les questions deviennent progressivement plus complexes.

Une fois le test complété, vous serez invité(e) à prendre un court rendez‑vous d'évaluation orale avec un membre de notre équipe.

La combinaison test écrit + entretien oral nous permet de déterminer votre niveau réel selon les standards Cultulangues.
